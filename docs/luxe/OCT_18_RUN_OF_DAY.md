## How we actually run triads (read this first)

| Layer | Rule |
|-------|------|
| **Booking** | Every senior assigned **Triad T1–T8** · same **arrival window** as triad mates |
| **Valet / drive** | **3 cars** pull up together · load **3 families** · cross to exit · next triad called on radio |
| **HMU** | **One triad owns all 3 chairs** for **47 min** · next triad starts when block clears |
| **Zones** | **3 zones · 3 photogs** — at steady state one senior per zone (different legs) · triad members are **12 min apart** at Z3 (not same minute) |
| **Sendoff** | **Batch release** — fastest senior **holds at mocktail porch** until **3rd of triad** is Mom-ready · then **“Triad N — valet”** |
| **Chalet** | Max **12 moms** = max **4 triads** on campus · traffic counts heads |

**Why hold at sendoff:** Z3 slots are serial (12 min). Without a porch hold, cars would come every 12 minutes. **Hold = valet loads 3 once.**

**Lunch 12:45–1:45 PM:** **Crew rotation** (not one sit-down for everyone). **T5 arrives** · new moms in as **T1–T2** have released. See § Lunch rotation.
